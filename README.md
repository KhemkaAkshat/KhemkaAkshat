## 👋 About Me

I'm **Akshat Khemka**, a Computer Science student and Full Stack Developer interested in building practical, user-focused applications.

I enjoy working across the entire development lifecycle — from designing frontend interfaces and REST APIs to working with databases, authentication, deployment, and application architecture.
